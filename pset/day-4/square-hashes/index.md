# A. Square of Hashes

## Problem Setup
- login to [CS50 IDE](https://cs50.dev)
- write `cd` in the *terminal* to go to the home directory
- write `mkdir square-hashes` to create a folder called `square-hashes`
- write `cd square-hashes` to go to the `square-hashes` folder
- write `code square-hashes.cpp` to create a file called `square-hashes.cpp` and open it in the editor

## Problem
Given a number **N**, print a square of hashes (`#`) of size **N** \(\times\) **N** (having **N** rows and **N** columns).

## Example

Here is how the program should run in the terminal. The inputs typed by the user are shown in **bold**.

```text
$ ./square-hashes
4
####
####
####
####
```

## How to Test
To test your program manually, compile it with `make` and run it:

```bash
make square-hashes
./square-hashes
```

To test your code automatically with `check50`, run:

```bash
check50 iti-technical-team/problemset/pset/4/square-hashes
```
