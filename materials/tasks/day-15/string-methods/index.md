# String Methods

## Objective
Practice manipulating string variables in JavaScript using standard string methods.

## Problem Setup
- Open [CS50 IDE](https://cs50.dev)
- Write `cd` in the *terminal* to go to the home directory
- Write `mkdir string-methods` to create a folder called `string-methods`
- Write `cd string-methods` to go to the `string-methods` folder
- Write `code string-methods.js` to create a file called `string-methods.js` and open it in the editor

## Requirements

Write a JavaScript program in `string-methods.js` that:
1. Declares a string variable containing your favorite quote.
2. Displays the original quote to the console.
3. Applies at least **two string methods** to manipulate the quote (such as `.toUpperCase()`, `.toLowerCase()`, `.replace()`, `.trim()`, or `.split()`).
4. Displays the modified results to the console.

### Example Output
```text
Original Quote: Learn from yesterday, live for today, hope for tomorrow.
Uppercase: LEARN FROM YESTERDAY, LIVE FOR TODAY, HOPE FOR TOMORROW.
Replaced: Learn from the past, live for today, hope for tomorrow.
```
