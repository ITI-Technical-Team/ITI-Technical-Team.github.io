# Favorite Movies

## Objective
Practice creating and manipulating arrays in JavaScript using array methods.

## Problem Setup
- Open [CS50 IDE](https://cs50.dev)
- Write `cd` in the *terminal* to go to the home directory
- Write `mkdir favorite-movies` to create a folder called `favorite-movies`
- Write `cd favorite-movies` to go to the `favorite-movies` folder
- Write `code favorite-movies.js` to create a file called `favorite-movies.js` and open it in the editor

## Requirements

Write a JavaScript program in `favorite-movies.js` that:
1. Creates an array containing **5** of your favorite movies.
2. Displays the entire list/array of movies using `console.log()`.
3. Updates the movie array by applying at least **two array methods** (such as `.push()`, `.pop()`, `.shift()`, `.unshift()`, or `.splice()`).
4. Displays the updated list/array of movies to the console.

### Example Output
```text
Original Movies: [ 'Inception', 'The Dark Knight', 'Interstellar', 'The Matrix', 'Avatar' ]
Updated Movies: [ 'The Dark Knight', 'Interstellar', 'The Matrix', 'Avatar', 'The Godfather' ]
```
