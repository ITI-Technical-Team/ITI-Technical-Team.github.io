# One Condition

## Problem Setup
- Create a folder called `one-condition` on your computer/IDE.
- Open [Scratch](https://scratch.mit.edu/projects/editor/).
- Create a project following the problem description below.
- Once finished, save your project to your computer. Click **File > Save to your computer**.
- Save the file as `project.sb3` inside your `one-condition` folder.

## Problem
Create a Scratch project that contains **at least one conditional** block.

### Requirements:
1. Use at least one conditional block from the Control category (e.g. `if` or `if-else`).
2. Make sure your sprite does some action inside the conditional block.

## How to Test
To test your code automatically with `check50`, run:

```bash
check50 iti-technical-team/problemset/pset/lec/1/one-condition
```

## Submit Your Code
Make sure you are in the `one-condition` directory, then run the following command:

```bash
submit50 iti-technical-team/problemset/pset/lec/1/one-condition
```
