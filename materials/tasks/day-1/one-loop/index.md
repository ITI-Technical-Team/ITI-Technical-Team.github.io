# One Loop

## Problem Setup
- Create a folder called `one-loop` on your computer/IDE.
- Open [Scratch](https://scratch.mit.edu/projects/editor/).
- Create a project following the problem description below.
- Once finished, save your project to your computer. Click **File > Save to your computer**.
- Save the file as `project.sb3` inside your `one-loop` folder.

## Problem
Create a Scratch project that contains **at least one loop** block.

### Requirements:
1. Use at least one loop block from the Control category (e.g. `repeat [10]`, `forever`, or `repeat until`).
2. Make sure your sprite does some action inside the loop.

## How to Test
To test your code automatically with `check50`, run:

```bash
check50 iti-technical-team/problemset/pset/lec/1/one-loop
```

## Submit Your Code
Make sure you are in the `one-loop` directory, then run the following command:

```bash
submit50 iti-technical-team/problemset/pset/lec/1/one-loop
```
