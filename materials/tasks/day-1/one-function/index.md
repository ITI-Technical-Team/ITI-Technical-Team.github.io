# One Function

## Problem Setup
- Create a folder called `one-function` on your computer/IDE.
- Open [Scratch](https://scratch.mit.edu/projects/editor/).
- Create a project following the problem description below.
- Once finished, save your project to your computer. Click **File > Save to your computer**.
- Save the file as `project.sb3` inside your `one-function` folder.

## Problem
Create a Scratch project that contains **at least one custom function (block)**.

### Requirements:
1. Create a custom block in the **My Blocks** category.
2. Define the block and use it in your code to perform an action.

## How to Test
To test your code automatically with `check50`, run:

```bash
check50 iti-technical-team/problemset/pset/lec/1/one-function
```

## Submit Your Code
Make sure you are in the `one-function` directory, then run the following command:

```bash
submit50 iti-technical-team/problemset/pset/lec/1/one-function
```
