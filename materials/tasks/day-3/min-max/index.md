# Min Max of Three

## Problem Setup
- login to [CS50 IDE](https://cs50.dev)
- write `cd` in the *terminal* to go to the home directory
- write `mkdir min-max` to create a folder called `min-max`
- write `cd min-max` to go to the `min-max` folder
- write `code min-max.cpp` to create a file called `min-max.cpp` and open it in the editor

## Problem
Given three numbers **A**, **B**, and **C**, print the **minimum** and **maximum** value.

Your program should output the prompts `A = `, `B = `, and `C = ` before reading each input.

## Example

Here is how the program should run in the terminal. The inputs typed by the user are shown in **bold**.

```text
$ ./min-max
A = 1
B = 2
C = 3
Minimum = 1 and Maximum = 3
```

## How to Test
To test your program manually, compile it with `make` and run it:

```bash
make min-max
./min-max
```

To test your code automatically with `check50`, run:

```bash
check50 iti-technical-team/problemset/pset/lec/3/min-max
```

## Submit Your Code
Make sure you are in the `min-max` directory, then run the following command:

```bash
submit50 iti-technical-team/problemset/pset/lec/3/min-max
```
