# Min Max of Three

Given three numbers **A**, **B**, and **C**, print the **minimum** and **maximum** value.

## Example Runs

Your program should output the prompts `A = `, `B = `, and `C = ` before reading each input.

### Example 1
```text
A = 1
B = 2
C = 3
Minimum = 1 and Maximum = 3
```

### Example 2
```text
A = 1
B = 1
C = 1
Minimum = 1 and Maximum = 1
```

### Example 3
```text
A = 2
B = 1
C = 2
Minimum = 1 and Maximum = 2
```

## Setup

Create a directory named `min-max` on your system and create a file named `min-max.cpp` inside it.

```bash
mkdir min-max
cd min-max
code min-max.cpp
```

Write your C++ program in `min-max.cpp`.

## Testing

You can test your program manually by compiling and running it:

```bash
g++ -o min-max min-max.cpp
./min-max
```

Or you can use `check50` to test your code automatically:
