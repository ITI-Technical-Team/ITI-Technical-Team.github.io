# Sort Descending

## Problem Setup
- login to [CS50 IDE](https://cs50.dev)
- write `cd` in the *terminal* to go to the home directory
- write `mkdir sort-descending` to create a folder called `sort-descending`
- write `cd sort-descending` to go to the `sort-descending` folder
- write `code sort-descending.cpp` to create a file called `sort-descending.cpp` and open it in the editor

## Problem
Write a program that declares an array of 7 integers initialized with the values `{10, 20, 30, 40, 50, 60, 70}` (which are in ascending order) and prints the numbers in descending order.

## Example

Here is how the program should run in the terminal:

```text
$ ./sort-descending
Numbers in descending order: 70 60 50 40 30 20 10 
```

## How to Test
To test your program manually, compile it with `make` and run it:

```bash
make sort-descending
./sort-descending
```

To test your code automatically with `check50`, run:

```bash
check50 iti-technical-team/problemset/pset/lec/5/sort-descending
```
