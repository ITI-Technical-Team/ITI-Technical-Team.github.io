# Scores Greater than 10

## Problem Setup
- login to [CS50 IDE](https://cs50.dev)
- write `cd` in the *terminal* to go to the home directory
- write `mkdir scores-greater-than-10` to create a folder called `scores-greater-than-10`
- write `cd scores-greater-than-10` to go to the `scores-greater-than-10` folder
- write `code scores-greater-than-10.cpp` to create a file called `scores-greater-than-10.cpp` and open it in the editor

## Problem
Write a program that takes scores from the user and prints the number of scores strictly greater than 10.

**Note:** You must store the scores in an array! Without an array, the solution will be considered incorrect.

## Example

Here is how the program should run in the terminal. The inputs typed by the user are shown in **bold**.

```text
$ ./scores-greater-than-10
Enter the number of elements : **5**
Enter element number 1 : **5**
Enter element number 2 : **1**
Enter element number 3 : **15**
Enter element number 4 : **2**
Enter element number 5 : **10**
number of scores greater than 10 : 1
```

## How to Test
To test your program manually, compile it with `make` and run it:

```bash
make scores-greater-than-10
./scores-greater-than-10
```

To test your code automatically with `check50`, run:

```bash
check50 iti-technical-team/problemset/pset/lec/5/scores-greater-than-10
```
