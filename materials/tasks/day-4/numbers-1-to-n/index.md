# Numbers 1 to N

## Problem Setup
- login to [CS50 IDE](https://cs50.dev)
- write `cd` in the *terminal* to go to the home directory
- write `mkdir numbers-1-to-n` to create a folder called `numbers-1-to-n`
- write `cd numbers-1-to-n` to go to the `numbers-1-to-n` folder
- write `code numbers-1-to-n.cpp` to create a file called `numbers-1-to-n.cpp` and open it in the editor

## Problem
Given a number **N**, print all numbers from 1 to **N** space-separated on a single line.

## Example

Here is how the program should run in the terminal. The inputs typed by the user are shown in **bold**.

```text
$ ./numbers-1-to-n
5
1 2 3 4 5
```

## How to Test
To test your program manually, compile it with `make` and run it:

```bash
make numbers-1-to-n
./numbers-1-to-n
```
