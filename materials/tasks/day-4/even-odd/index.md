# Even or Odd Function

## Problem Setup
- login to [CS50 IDE](https://cs50.dev)
- write `cd` in the *terminal* to go to the home directory
- write `mkdir even-odd` to create a folder called `even-odd`
- write `cd even-odd` to go to the `even-odd` folder
- write `code even-odd.cpp` to create a file called `even-odd.cpp` and open it in the editor

## Problem
Write a function that takes only one integer number and returns whether the number is `Even` or `Odd`.

In your `main` function, read an integer, call your function, and print the result.

## Examples

**Example 1:**
```text
$ ./even-odd
2
Even
```

**Example 2:**
```text
$ ./even-odd
5
Odd
```

## How to Test
To test your program manually, compile it with `make` and run it:

```bash
make even-odd
./even-odd
```

To test your code automatically with `check50`, run:

```bash
check50 iti-technical-team/problemset/pset/lec/4/even-odd
```

## Submit Your Code
Make sure you are in the `even-odd` directory, then run the following command:

```bash
submit50 iti-technical-team/problemset/pset/lec/4/even-odd
```
