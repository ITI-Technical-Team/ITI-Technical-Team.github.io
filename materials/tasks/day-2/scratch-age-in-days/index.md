# Age in Days (Scratch)

## Problem Setup
- Open [Scratch](https://scratch.mit.edu/projects/editor/)
- Follow the instructions below to create your project.
- Once finished, save your project to your computer. Click **File > Save to your computer**. The file should end in `.sb3`.

## Problem
Create a Scratch project with a custom block (function) that takes your **age** as an input and **says (prints) your age in days** (consider the whole year has 365 days).

$$\text{Age in Days} = \text{age} \times 365$$

### Requirements:
1. Create a custom block in the **My Blocks** category.
2. The custom block must take a number input (parameter) for `age`.
3. Use a multiplication block `*` from the Operators category to calculate the days (`age * 365`).
4. Use a **Say** block to display the result.
